GESTURE COMMANDS:
-----------------
1. MOUSE MOVE:  Index Finger UP (One finger)
2. LEFT CLICK:  Pinch Thumb + Index (Quickly)
3. NEXT SLIDE:  Peace Sign (Two fingers)
4. PLAY/PAUSE:  Open Palm (High Five)
5. DESKTOP:     Closed Fist (Rock)
6. VOLUME:      While in Mouse Mode (Index Up), tilt hand left/right.

TROUBLESHOOTING:
----------------
- Mouse Jittering? Increase light (use phone flashlight).
- Not Detecting?   Make sure glove contrasts with shirt (Black Glove/White Shirt).
- Lag?             Check if laptop is plugged into power (Performance Mode).
